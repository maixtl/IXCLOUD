# Minecraft Server Web Control Panel

**Русская версия** / **English version**

---

## Описание

Minecraft Server Web Control Panel — это удобная панель управления для вашего Minecraft сервера. С помощью этой панели вы сможете легко управлять настройками сервера, пользователями, плагинами и многим другим через интуитивно понятный интерфейс. Эта панель разработана для того, чтобы упростить процесс администрирования и улучшить игровой опыт для владельцев серверов.

---

## Особенности

- **Управление серверами**: Создавайте и настраивайте несколько серверов Minecraft.
- **Пользователи и права**: Управление правами пользователей и групп.
- **Плагины и моды**: Легкая установка и управление плагинами.
- **Безопасность**: Защита от несанкционированного доступа с помощью многоуровневой аутентификации.
- **Мониторинг**: Мониторинг производительности серверов в реальном времени.
- **Автозапуск**: Настройка автозапуска серверов и автоматические перезагрузки.
- **Логирование**: Детализированные логи работы серверов.
- **Совместимость**: Поддержка различных версий Minecraft (например, 1.16.5, 1.18.x, 1.19.x).

---

## Установка

### Требования

- Веб-сервер (например, Apache или Nginx)
- PHP 7.4 или выше
- MySQL или MariaDB
- Minecraft сервер

### Шаги установки

1. Скачайте последнюю версию панели с [GitHub](https://github.com/your-repository).
2. Разархивируйте файлы на вашем веб-сервере.
3. Настройте конфигурацию базы данных и подключение к серверу Minecraft в файле `config.php`.
4. Запустите установочный скрипт, чтобы настроить базу данных и начальную конфигурацию.
5. Доступ к панели можно получить по адресу: `http://yourdomain.com`.

---

## Использование

- После успешной установки вы можете войти в панель с учетными данными администратора.
- В разделе **Сервера** создавайте новые серверы и настраивайте их параметры.
- В разделе **Пользователи** управляйте правами доступа для каждого пользователя.
- Раздел **Логи** поможет вам отслеживать события на сервере.

## Minecraft Server Web Control Panel (English)

The Minecraft Server Web Control Panel is an easy-to-use tool for managing your Minecraft server. With this panel, you can manage server settings, users, plugins, and more, all through an intuitive web interface. Designed to simplify administration, this panel enhances the server owner's experience.

---

## Features

- **Server Management**: Create and manage multiple Minecraft servers.
- **Users & Permissions**: Manage user and group permissions.
- **Plugins & Mods**: Easily install and manage plugins.
- **Security**: Multi-level authentication to prevent unauthorized access.
- **Monitoring**: Real-time performance monitoring of your servers.
- **Autostart**: Set up automatic server restarts and start-ups.
- **Logging**: Detailed server activity logs.
- **Compatibility**: Supports various Minecraft versions (e.g., 1.16.5, 1.18.x, 1.19.x).

---

## Installation

### Requirements

- Web server (Apache or Nginx recommended)
- PHP 7.4 or higher
- MySQL or MariaDB
- Minecraft server

### Installation Steps

1. Download the latest version of the panel from [GitHub](https://github.com/your-repository).
2. Extract the files to your web server.
3. Configure the database and Minecraft server connection in the `config.php` file.
4. Run the installation script to set up the database and initial configuration.
5. You can access the panel at: `http://yourdomain.com`.

---

## Usage

- After installation, you can log into the panel using your admin credentials.
- In the **Servers** section, create new servers and configure their settings.
- In the **Users** section, manage access rights for each user.
- The **Logs** section helps you track server activity.
